# Vidéo promo — Soleilenterrasse

`soleil-en-terrasse-promo.mp4` : 45 s, vertical 1080×1920, 30 i/s, H.264 + AAC (Reels, TikTok, Shorts, Stories).

Design épuré, fond blanc, centré sur la 3D. Toutes les images de l’app sont de vraies captures (carte 3D réelle, 21 juin, Bordeaux).

| Temps | Séquence |
|---|---|
| 0–6 s | Écran d’accueil de l’app (soleil, logo, accroche, barre « La 3D se prépare… ») |
| 6–16 s | 3D plein écran, place Meynard : l’ombre de la flèche Saint-Michel tourne de 7h à 21h, La Mère Michel en étoile |
| 16–22 s | Pour vous : le curseur d’heure dans l’app, les ombres bougent |
| 22–27 s | Motion design : les villes défilent, compteur jusqu’à 11 482 terrasses |
| 27–31 s | Pour vous : liste, filtre Bars |
| 31–38 s | Pour les restaurateurs : La Mère Michel en étoile sur la carte, badge Sélection |
| 38–45 s | Écran de fin : « Trouve ta place au soleil. », App Store, « Restaurateurs : rejoignez la Sélection. » |

Le chiffre 11 482 est la somme des terrasses des fichiers `data/*.json` (9 villes).

- `captures/` : une sélection des captures réelles utilisées.
- `source/` : scripts de capture (`sweep2.js`, `sweep_app.js`, `lib.js`), animation (`composition.html`), rendu image par image (`render2.js`) et musique originale générée (`music3.py`).
